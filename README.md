# Space Discoveries 🚀
A responsive web application dedicated to exploring the wonders of the universe, from the latest exoplanet breakthroughs to stunning galactic imagery.

## 🛠️ Technologies Used
This project utilizes a modern full-stack suite focused on performance, responsive design, and interactive user experiences:

* **Frontend Core:** HTML5, CSS3 (Mobile-First Design)
* **Dynamic Scripting:** Vanilla JavaScript (ES6+) for DOM manipulation and asynchronous data handling.
* **Animations:** * **HTML5 Canvas:** Interactive starfield background with depth-based perspective.
    * **Scroll-Linked Animations:** Earth image scaling and opacity transitions based on viewport progress.
* **Data Management:** JSON-based "Article Database" for dynamic news rendering.
* **Typography & Icons:** Google Fonts (Orbitron) and FontAwesome 6.
* **Tooling:** VS Code with Live Server integration.

## 🚀 Key Features
* **Interactive Starfield:** A custom-built Canvas engine that simulates travel through a starfield.
* **Responsive Navigation:** A fully functional hamburger menu for mobile users.
* **Dynamic Article Routing:** View detailed scientific discoveries via URL parameters and a shared template.
* **Form Validation:** Real-time client-side validation for the community join form.
